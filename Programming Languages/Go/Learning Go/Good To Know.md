## Go Programs Compile to a Single Binary
---
- They do not require any additional software to be installed to run them.
- This contrasts with Java, Python, and JS which requires you to install a VM to run the program.
- Using a single native binary makes it easier to distribute Go programs.
- Developers often use Docker or Kubernetes to package Go apps inside a scratch or distroless image.
