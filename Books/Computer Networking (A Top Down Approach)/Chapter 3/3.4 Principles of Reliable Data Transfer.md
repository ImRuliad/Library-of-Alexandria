## RDT 2.0 - Reliable Data Transfer Over a Channel with Bit Errors
---
*A more realistic model, where bits in a packet may be corrupted.*
*These bit errors / corruptions typically occur in the physical components of a network as a packet is transmitted.*

Imagine a phone call where you response "OK" for acknowledging received information and "Say that again" for things you missed.
This is the basis of ARQ (Automatic Repeat reQuest).

There are three fundamental protocol capabilities required in ARQ to handle the presence of bit errors:

| Protocol          | Description                                                                                                                                                                                                                                                                                                                                   |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Error Detection   | A mechanism to allow a receiver to detect when bit errors have occured.<br>UDP uses checksum field for exactly this reason.<br><br>This requires extra bits (beyond the bits of original data to be transferred) to be sent from sender to receiver.<br>These bits will be gathered into the packet checksum field of the rdt2.0 data packet. |
| Receiver Feedback | ACK (Acknowledge) and NAK (Negative Acknowledge) replies lets the receiver tell the sender whether or not packets we successfully received.<br>Only one bit needed (0 = NAK, 1 = ACK)                                                                                                                                                         |
| Retransmission    | A packet that is received in error at the receiver will be retransmitted by the sender.                                                                                                                                                                                                                                                       |
