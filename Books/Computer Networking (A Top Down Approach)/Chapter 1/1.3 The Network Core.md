# 1.3.1 Packet Switching
*In Network Applications, End Systems exchange messages with each other.*

- Information sent between source and destination end systems is broken up into packets.
- Each packet travels through comms links and packet switches.
- Two types of packet switches: routers and link-layer switches.
- Packets transmitted over each comm link equal to the rate of the full transmission rate of the link.

*If a source end system or packet switch is sending a packet of L bits over a link with transmission rate R bits/sec then the time to transmit the packet is L/R seconds*

$$
\begin{align}
L &= bits\;in\;a\;packet\;from\;source\;end\;system \\
R &= bits/sec\;of\;transmission\;link \\
Z &= time\;to\;transmit\;packet \\
Z &= L/R\;seconds
\end{align}
$$

---

#### ***Store-and-forward Transmission***
*Most packet switches use store-and-forward transmission at the inputs to the links.*

- Packet switch must receive the entire packet before it can begin to transmit the first bit of the packet onto the outbound link.
- Buffers (stores) the packets bits until all bits in the packet are received.
- Once all bits in a packet are received, packet is sent to outgoing link.

> [!NOTE] Example
> *How long does it take for a source sending three packets, each consisting of L bits, to send to the destination?*

- At time t=0 seconds, source begins to transmit.
- At time L/R seconds, source has transmitted the entire packet, packet has been received and stored at the router.
- At time L/R seconds, router can begin to transmit the packet onto the outbound link towards destination.
- At time 2L/R seconds, router has transmitted the entire packet, and the entire packet has been received by the destination.
- Total delay is 2L/R seconds.
*If the switch instead forwarded bits as soon as they arrive, the delay would be L/R*

*The equation for sending one packet from source to destination over a path consisting of N links each of rate R is the following*

*Assume*
$$
\begin{align}
L &= bits\;in\;packet\;of\;source\;system \\
R &= bits/sec\;of\;transmission\;link \\
N &= Number\;of\;links \\
\end{align}
$$
*Then*
$$
\begin{align}
d_{end-to-end} = N \frac{L}{R}
\end{align}
$$
---
#### ***Queueing Delays and Packet Loss***
*Each packet switch has multiple links attached to it.*

- For each link attached, the packet switch has an ***output buffer*** or ***output queue***.
- ***output buffer*** stores packets that is about to be sent to the link.
- An arriving packet must wait in the ***output buffer*** if the link is busy with the transmission of another packet.
- Packets can also suffer ***queueing delays*** depending on the level of congestion in the network.
- If the ***output buffer*** is full with packets, then ***packet loss*** will occur.
- In ***packet loss*** either the arriving packet or on of the already queued packets will drop.

#### ***Forwarding Tables & Routing Protocols***
*How does the router determine which link it should forwards the packet onto?*

- Source end system includes destination's IP address in the packets header.
- Packet arrives at the router in the network.
- Router examines a portion of the packet's destination address.
- Router forwards the packet to an adjacent router.
- Each router has a ***Forwarding Table*** that maps destination addresses to that router's outbound links.
- Router directs the packet to this outbound link.

# 1.3.2 Circuit Switches
*Two fundamentals of moving data through a network: circuit switching & packet switching.*

- A circuit in a link is implemented with one of two multiplexing techniques.
	- ***Frequency-division Multiplexing (FDM)***
	- ***Time-division Multiplexing (TDM)***\

---
#### ***Frequency-division Multiplexing***
- ***FDM*** divides the frequency spectrum of a link for each connection established on the link.
- The link dedicates each frequency band to each connection for the duration of the connection.
- Typically 4,000 Hz for telephone networks.
- The width of the band is called ***Bandwidth***
- FM radio stations also use ***FDM*** to share the frequency spectrum among each station.

![[Pasted image 20260910135600.png]]

*In this example above, FDM is illustrated for a specific network link supporting up to 4 circuits.*
- Frequency Domain is split into four bands.
- Each band of bandwidth 4 KHz

---

#### ***Time-division Multiplexing***

- Time is divided into frames of a fixed duration
- each frame divided into a fixed number of time slots
- When the network establishes a connection across a link, the network dedicates one time slot in every frame to this connection

![[Pasted image 20260910135529.png]]

*In this example above, TDM is illustrated for a specific network link supporting up to 4 circuits.*
- Time domain is segmented into frames
- Each frame containing four time slots.
- Each circuit is assigned the same dedicated slot in the revolving TDM frames.


> [!INOTE] For TDM, the transmission rate of a circuit is equal to the frame rate multiplied by the number of bits in a slot.
> If the link transmits 8,000 frames per second and each slot contains 8 bits, then the transmission rate of each circuit is 64 Kbps



> [!NOTE] Example
> How long does it take to send a file of 640,000 bits from Host A to Host B over a circuit-switched network. Suppose all links use TDM with 24 slots and have a bit rate of 1.536 Mbps. Also suppose it takes 500 msec to establish an end-to-end circuit before Host A can begin to transmit the file.
> 
- Each circuit has a transmission rate of 1.536 Mbps/24 = 64 kbps
- time to transmit file is (640,000 bits)/(64 kbps) = 10 seconds to transmit file
- Adding the 500 milliseconds makes it 10.5 total seconds.
- Note that the transmission time is independent of the number of links.
