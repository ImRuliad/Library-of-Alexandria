
- End Systems are referred to as hosts because they host programs like Web Browsers, etc...
- Hosts and End Systems are interchangeable terms.
- Hosts can be divided into two categories: Clients and Servers.
- Clients tend to be desktops, laptops, smartphones, etc....
- Servers are powerful machines that store and distribute Web Pages, stream video, etc...

# 1.2.1 Access Networks
*Access Network is a network that physically connects an end system to the first router (aka edge router) on a path from the end system to any other distant end system.*

The Two most prevalent types of broadband residential access are Digital Subscriber Line and Cable.

---
#### ***DSL (Digital Subscriber Line)***
*Obtains Internet Access from the same local telephone company that provides its wired local phone access*

- Each customer's DSL modem uses existing telephone line
- Exchanges data with a DSLAM (Digital Subscriber Line Access Multiplexer) 
- DSLAM located in telco's CO (Central Office)
- DSL Modem turns digital data into high-frequency tones
- high-frequency tones transmitted over telco wire to the CO
- Translated back into digital format at the DSLAM
- On the Customer side, a splitter separates data and phone signals
- data signals get forwarded to the DSL modem
- In the CO, DSLAM separates data and phone signals
- data signals get sent to the Internet.

| High Speed Downstream Channel          | **50 kHz to 1 MHz band** |
| -------------------------------------- | ------------------------ |
| **Medium Speed Downstream Channel**    | **4 kHz to 50 kHz band** |
| **Ordinary Two-Way Telephone Channel** | **0 to 4 kHz band**      |

#### ***Cable***
*Cable makes use of television companies existing cable infrastructure*
- Requires special modems called cable modems.
- Cable Modem Termination System serves same purpose as DSLAM in DLS
- CMTS turns analog signal sent from cable modems in many downstream homes back into digital format.
- Cable modems divide HFC network into downstream channel and upstream channel.
- Access/speed is asymmetric

| Standard   | Upstream | Downstream |
| ---------- | -------- | ---------- |
| DOCSIS 2.0 | 30 Mbps  | 40 Mbps    |
| DOCSIS 3.0 | 100 Mbps | 1.2 Gbps   |

---
#### ***Hybrid Fiber Coax (HFC)***
- Fiber optics connect cable head to end neighborhood-level junctions
- Traditional coax cable then used between junction to individual homes.
- Each junction supports ~500 to 5000 homes.
- This is a Hybrid Fiber Coax (HFC) infrastructure.

#### ***Fiber To The Home (FTTH)***
*Provides an optical path from the CO directly to the home.*

- Fiber leaving the CO is shared by many homes.
- Fiber is split into individual customer-specific fibers once it is closer to the home.
- Two competing optical-distribution network architectures: Active Optical Networks (AONs) and Passive Optical Networks (PONs).
![[Pasted image 20260909131601.png]]

- Each home has an Optical Network Terminator (ONT)
- Each ONT is connected to a neighborhood-dedicated Optical Fiber Splitter (OFS).
- Combines the Fiber lines from each home ( >100 homes) into a shared Fiber Line.
- OFS connects to an Optical Line Terminator (OLT) in the telco's CO.
- OLT converts between optical and electrical signals.
- OLT connects to the internet via a telco router.
- At home, users connect a home router to the ONT to access the internet.
