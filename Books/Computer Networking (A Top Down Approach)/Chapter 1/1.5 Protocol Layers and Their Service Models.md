#### ***Application Layer***
*Where network applications and their application-layer protocols reside*

- **HTTP** - Provides web document request and transfer.
- **FTP** - Provides for transfer of files between two end systems.
- **SMTP** - Provides transfer of e-mail messages.
- **DNS** - translates 32-bit network address (IP Address) into a human readable name.

*Application layer protocols are distributed over multiple end systems.*

*The application layer in one system is used to exchange packets of information with the application layer of another system*

*This is called a message.*

---
#### ***Transport Layer***
*Transports application-layer messages between application endpoints*

**TCP**
- Provides a connection-oriented service to applications
- Guarantees delivery of application-layer messages to destination
- Flow control, sender/receiver speed matching
- Breaks long messages into shorter segments
- Provides congestion control mechanism (throttles transmission rate when network is congested)

**UDP**
- Connectionless service to applications
- No reliability
- No flow control
- No congestion control

---
#### ***Network Layer***
*Moves network-layer packets, known as datagrams, from one host to another*

- The transport-layer protocol (TCP or UDP) in a source host passes a segment and destination address to the network layer
- The network layer then provides the service of delivering the segment to the transport layer in the destination host.
- Network layer includes the IP Protocol, which defines the fields in the datagram.
- Also defines how end systems and routers act on these fields.
- There is only one IP Protocol
- Network layer also contains routing protocols that determine the routes datagrams take between sources and destinations

---
#### ***Link Layer***
*Moves a packet from one node to the next node in the route*

- At each node, Network Layer passes the datagram down to the link layer.
- Delivers the datagram to the next node.
- At the next node, the link layer passes the datagram back up to the Network Layer.
- Each link may have its own link-layer protocol
- Link-layer protocols include Ethernet, WiFi, and Cable Access Network's DOCSIS
- Link-layer packets are known as Frames

---
#### ***Physical Layer***
*Moves individual bits within the frame from one node to the next*

- Protocols at this layer are link dependent
- Depend on the transmission medium of the link
- Twisted-Pair Copper wire, SMF, MMF, etc...
